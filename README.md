# 🧠 MemoPlan — Telegram-бот интервального повторения

Легковесный и современный Telegram-бот для долгосрочного запоминания информации на основе концепции **«Тем»** с таймлайнами, дневным батчингом сна (Sleep-Aware) и умными групповыми уведомлениями без спама.

---

## 🌟 Ключевые возможности

### 1. Архитектура сущности «Тема» (Topic)
В отличие от классических колод карточек Anki, единицей системы является **тема со статусом и таймлайном**:
* **Заголовок:** название темы (например, `Команда grep`, `SQL оконные функции`).
* **Шпаргалка / Заметки:** скрываемый контекст с флагами, примерами команд или ссылками.
* **Стейдж (шаг интервала):** целое число от 0 до N.
* **Сетка шагов:** настраиваемые интервалы.
* **Таймлайн:** точное время следующего повторения (`next_review_at`).
* **История:** логи с оценками сложности (`🟢 Помню отлично`, `🟡 С трудом`, `🔴 Забыл напрочь`).
* **Архив:** по завершении всех шагов тема переходит в раздел **«Навсегда в долговременной памяти»**.

---

### 2. Сетки интервалов (Пресеты)

* **⏱ Стандартный (по умолчанию, 7 этапов):**
  * `0 → 1:` +20 минут *(сразу после создания, первичное закрепление)*
  * `1 → 2:` +12 часов *(вечером того же дня / на следующее утро)*
  * `2 → 3:` +24 часа (1 день) *(на следующий день)*
  * `3 → 4:` +3 дня *(через пару дней)*
  * `4 → 5:` +7 дней *(спустя неделю)*
  * `5 → 6:` +14 дней *(через две недели)*
  * `6 → 7:` +30 дней *(через месяц)*
  * `7:` 🏆 Переход в архив **«Навсегда в долговременной памяти»**

* **⚡️ Экзамен (Интенсив, 4 этапа):**
  * `20 мин` → `2 часа` → `12 часов` → `24 часа` → 🏆

* **🧠 Долговременный (5 этапов):**
  * `20 мин` → `12 часов` → `3 дня` → `10 дней` → `30 дней` → 🏆

---

### 3. Дневной батчинг (Sleep-Aware Scheduling)
Если расчётное время повторения выпадает на ночные часы (по умолчанию: `23:00 — 09:00`):
* Бот **автоматически переносит срок на утро (09:00)** в часовом поясе пользователя.
* Вы не получаете ночных уведомлений и просроченных очередей во время сна.
* Часы сна и часовой пояс настраиваются в меню `/settings`.

---

### 4. Уведомления без спама (Smart Notification Batching)
* Фоновый планировщик отслеживает созревшие темы каждые 60 секунд.
* Темы группируются: если готово 3 темы, приходит **одно лаконичное сообщение**:
  > 🔔 **Пора повторить (3):**
  > • Команда grep, Git rebase, SQL CTE
  > `[▶️ Начать повторение]`
* Защита от спама: бот не повторяет уведомление по одним и тем же темам каждые пару минут (действует кулдаун).
* Во время сна уведомления приостанавливаются.

## 🚀 Быстрый запуск

### Шаг 1. Получите токен бота
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя (например, `MyMemoPlanBot`) и юзернейм (например, `my_memoplan_bot`).
4. Скопируйте выданный HTTP API Token (вида `123456789:ABCdefGHIjkl...`).

### Шаг 2. Запуск проекта

Вы можете запустить бота одной командой через `./run.sh`:

```bash
./run.sh
```

При первом запуске скрипт автоматически:
1. Создаст изолированное виртуальное окружение `.venv`
2. Установит необходимые зависимости
3. Предложит ввести токен бота прямо в терминале (или прочитает его из `.env`)

Либо создайте файл `.env` вручную:
```bash
cp .env.example .env
# отредактируйте TELEGRAM_BOT_TOKEN в файле .env
./run.sh
```

## 📱 Интерфейс и сценарии использования

### Главное меню («Очередь на сегодня»)
Экран поделён на 3 понятных блока:
1. 🔴 **Готово к повторению:** список тем, созревших прямо сейчас, номер этапа и время с момента созревания. Кнопка `▶️ Начать повторение`.
2. 🟡 **Скоро (в течение дня):** темы, созревающие в ближайшие часы (например, `через 14 минут`).
3. 🔵 **Будущие темы:** темы на следующие дни и недели.

### Сессия повторения (Review Card)
1. Показывается карточка с названием темы и текущим этапом.
2. Кнопка `💡 Показать шпаргалку / заметки`: скрытый конспект открывается только после того, как вы мысленно вспомнили материал.
3. 3 кнопки исхода:
   * 🟢 **Помню отлично:** шаг увеличивается на +1, рассчитывается следующий интервал с учётом сна.
   * 🟡 **Вспомнил с трудом:** шаг остаётся текущим (повтор завтра для закрепления).
   * 🔴 **Забыл напрочь:** сброс на шаг 1 (+20 минут), перезапуск цикла закрепления.
4. После прохождения всех тем сессии бот поздравляет вас и сообщает время следующего подхода.

### Демо-режим для быстрого знакомства
Чтобы сразу протестировать интерфейс без ручного набора:
* Отправьте команду `/demo` (или выберите в настройках «🎁 Загрузить примеры тем»).
* Бот создаст 4 демонстрационные темы на разных этапах (включая тему, готовую к повторению прямо сейчас).

## 🛠 Автозапуск в Linux (Systemd Service)

Для непрерывной работы 24/7 в фоне:

1. Скопируйте юнит-файл в каталог служб пользователя:
```bash
mkdir -p ~/.config/systemd/user
cp memoplan.service ~/.config/systemd/user/
```

2. Активируйте и запустите службу:
```bash
systemctl --user daemon-reload
systemctl --user enable --now memoplan.service
```

3. Проверить статус:
```bash
systemctl --user status memoplan.service
```
